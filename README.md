# CS-340-Portfolio
CS-340 Module 8 Portfolio 

How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?
--------------------
I try to write programs that are organized and easy to understand so they are easier to troubleshoot and update later on. In Project One, I created a CRUD Python module to handle creating, reading, updating, and deleting records in MongoDB. In Project Two, I was able to reuse that module to connect the database to by dashboard instead of writing all of that database code again. This made the project easier to manage and helped to keep the code organized. In the future, I could reuse this module for other projects that need to store, search or update information in a database.



How do you approach a problem as a computer scientist? Consider how you approached the database or dashboard requirements that Grazioso Salvare requested. How did your approach to this project differ from previous assignments in other courses? What techniques or strategies would you use in the future to create databases to meet other client requests?
--------------------
When approaching a problem as a computer scientist, I start by understanding the requirements and breaking the problem into smaller steps. For the Grazioso Salvare project, I needed to make sure the database contained the correct animal information and that the dashboard could filter and display the results in a useful way. I worked on the database connection first and then connected it to the dashboard's table, map, and chart. This project was different from some of my previous assignments because I had to make multiple parts of an application work together instead of focusing on one specific programming task. In future projects, I would continue to review client requirements, organize work into smaller tasks, test each part, and make changes based on the results.


What do computer scientists do, and why does it matter? How would your work on this type of project help a company, like Grazioso Salvare, to do their work better?
--------------------
Computer scientists solve problems by developing software and systems that help people work more efficiently. In this project, I created a dashboard that could help Grazioso Salvare review animal shelter data and identify animals that match different rescue requirements. The filters and visual displays make it easier to find relevant information without manually searching through thousands of records. This type of work matters because it can save a lot of time, reduce unnecessary manual work, and help organizations make better decisions using their data. It also shows how programming and databases can be used to solve real-world problems.
